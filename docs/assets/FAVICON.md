# Favicon Prompt

Use the following prompt with an image generation tool (like Imagen) to create a favicon for the Cricket Scorecard PWA.

## Prompt

> A minimal, flat design favicon icon for a cricket app. It should feature a stylized cricket bat crossed with a red cricket ball on a clean, circular green background. The style should be modern, simple, and highly recognizable at small sizes (e.g., 32x32 or 16x16 pixels). Vector art style, no realistic details, clean lines.

## Instructions for Use

1.  Generate the image using the prompt above.
2.  Download the generated image.
3.  Convert it to `.ico` format or use it as a `.png` (recommended to have multiple sizes like 16x16, 32x32, 192x192 for PWA).
4.  Place the favicon files in the project directory and link them in `index.html`.
